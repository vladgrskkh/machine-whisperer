# Dashboard sources

These Grafana JSON files are provisioned directly from Git. Each uses the `mw-prometheus` data source and the scrape jobs defined by [issue #17](https://github.com/vladgrskkh/machine-whisperer/issues/17). The original SHA-256 values below are for the raw upstream dashboard files before adaptation.

| Local file | Pinned source and original SHA-256 | Adaptation |
| --- | --- | --- |
| `nginx.json` | [NGINX Prometheus Exporter v1.5.3](https://github.com/nginx/nginx-prometheus-exporter/blob/9956da7073198e272ff915c5e06c360290c50b6b/grafana/dashboard.json), `320b818e67fdefb30ff5a3e278bba51ccd55c29d3a62858962d55f7ec7d25828` | Ported upstream panels 8, 12 and 15 to stat and time series panels. Scoped them to `job="nginx"`, used the scrape-aware rate interval and added independent exporter scrape status. |
| `go-services.json` | [Go Mixin by Adin Hodović](https://github.com/adinhodovic/go-mixin/blob/f381b33cef1336173357467e859911fdf2ffb05c/dashboards_out/go-overview.json), `869a91701d945faced3d79724d8e99e224d1f4d1b631f942a33cf72ac6e1500f` | Adapted CPU, goroutines, heap and resident memory from upstream panels 8, 9, 16 and 15. Replaced Kubernetes variables and optional runtime metrics with the Compose service and instance filters and standard Go collector metrics. Added scrape health and business HTTP workload panels. |
| `postgres.json` | [Postgres Overview mixin from postgres_exporter v0.21.1](https://github.com/prometheus-community/postgres_exporter/blob/05ec47a115a2c5d813e64c664213a88682fc8dc7/postgres_mixin/dashboards/postgres-overview.json), `cc602a49af966cc1e61814460cfb5c2767698315514831af00445fc87a865cee` | Adapted upstream panels 11, 3, 12 and 13 for transaction and rollback rates, deadlock rate, buffer cache hit ratio and connections. Scoped database queries to `machine_whisperer` and added size, exporter scrape status and database availability. The exporter's default `database` and `stat_database` collectors supply these series. [Database collector](https://github.com/prometheus-community/postgres_exporter/blob/05ec47a115a2c5d813e64c664213a88682fc8dc7/collector/pg_database.go) · [Statistics collector](https://github.com/prometheus-community/postgres_exporter/blob/05ec47a115a2c5d813e64c664213a88682fc8dc7/collector/pg_stat_database.go) |
| `clickhouse.json` | [ClickHouse Overview mixin by Grafana Labs](https://github.com/grafana/jsonnet-libs/blob/05c398b4b1686af45bbf63913897688557c30671/clickhouse-mixin/dashboards_out/clickhouse-overview.json), `343b64266111a05bdc9d8b6678f797d5a7e7142677a5c6bfbd1747103517e4e4` | Adapted upstream panels 2, 3 and 6 for queries, failures and tracked memory. Scoped queries to the native Compose target and added scrape status, inserted rows and merge activity. [Native counters](https://github.com/ClickHouse/ClickHouse/blob/v26.9.36.3-stable/src/Common/ProfileEvents.cpp) · [Native gauges](https://github.com/ClickHouse/ClickHouse/blob/v26.9.36.3-stable/src/Common/CurrentMetrics.cpp) |
| `telemetry.json` | Machine Whisperer | Project-owned panels for the API, outbox relay, Analytics, detector and alerts. Queue panels use a maximum across live API instances with a successful snapshot less than 90 seconds old. Current queue stats map unavailable snapshots to “Unknown” and retain zero for a confirmed empty snapshot. |
